# Миграция GSD Core — 27 октября 2026

## Результат

Две активные глобальные установки — Codex и Claude Code — переведены на официальный GSD Core 1.19.0. Обновлены пять найденных проектных и исходных копий пакета. Старые runtime-папки убраны из этих семи мест после сохранения локальных резервных копий. Исторические установочные кэши и резервные архивы не считаются активными установками и не публикуются.

В Codex используется штатное размещение навыков ~/.agents/skills и самостоятельные TOML-файлы ролей в ~/.codex/agents. Старые таблицы отдельных ролей из config.toml заменены штатным механизмом обнаружения. Удалены устаревшие регистрации GSD для Codex; сторонние обработчики сохранены. Общая папка навыков Claude Code через пользовательские ссылки сохранена.

## Русский профиль

Словарь покрывает 72 команды и 35 ролей текущего upstream. Русифицированы описания, краткие названия, ответы и инструкции рабочего профиля. Добавлены русское руководство, повторяемый установщик и адаптер контекста Codex. Имена команд, ключи конфигурации, протоколы, права и модели не переводятся и не заменяются локализатором. Подробные технические workflows и оригинальные справочники остаются на языке upstream.

## Проверено

- Во всех семи найденных местах VERSION равен 1.19.0.
- 316 файлов остальных пользовательских навыков совпали с исходными контрольными суммами.
- Конфигурация Codex загружается; TOML-файлы агентов разбираются без ошибок.
- Утилита Core запускается; загрузчик настроек получает response_language = ru.
- Повторная установка через обёртку прошла для Codex и Claude Code.
- 11 автоматических проверок адаптации прошли: покрытие словарей, повторное применение, сохранение команд/моделей/прав, неизвестные команды, обработка ссылок, восстановление снимка, приоритет свежих данных, ограничения объёма и сохранение пользовательских обработчиков.
- Обработчик контекста возвращает данные штатного формата на входах трёх реальных проектов. Нативная команда Codex для просмотра состава контекста завершилась успешно без обращения к модели.

## Что требует действия пользователя

В Codex открыть /hooks, просмотреть и подтвердить новые определения shinobi-codex-context.py. Проверка доверия приложением не обходилась, trusted_hash вручную не переписывался. До подтверждения автоматический запуск новых обработчиков не считается активным. После установки начать новый чат или перезапустить приложение для обновления списка навыков и ролей.

## Границы проверки

Реальное сокращение контекста пользовательской сессии с последующим автоматическим восстановлением ещё не наблюдалось. Не проводился полный цикл разработки проекта через Core и сравнительный тест качества моделей. Запись контекста не гарантирует сохранение незаписанных решений. Миграция сама по себе не означает обновление или публикацию пользовательских сайтов.

Резервные копии настроек и локальных разрешений хранятся только на устройстве. В GitHub, Google Диск и Notion передаются исходники адаптации и этот отчёт, без конфигураций учётных записей, разрешений и кэшей.
