# GSD Core — версия Shinobi

Форк: https://github.com/shinobiSoStandom/gsd-core/tree/shinobi-ru

Основа: OpenGSD GSD Core 1.19.0, лицензия MIT. Это пользовательская адаптация, а не официальный русский релиз OpenGSD. Оригинальные файлы ядра и лицензия сохранены.

## Что переведено и адаптировано

- Русские названия в кратких описаниях и описания 72 навыков.
- Описания 35 ролей GSD, включая проверки интерфейсов, кода и интеграций.
- Русский язык ответов, вопросов и новых документов через штатный response_language и инструкции профиля.
- Русское руководство по командам и правила работы Shinobi.
- Повторяемое применение адаптации после установки и обновления.
- [Восстановление контекста Codex](CODEX-CONTEXT.ru.md) через его штатные события.

Технические исходники, подробные оригинальные workflows и справочники остаются на языке upstream. Команды, ключи JSON/TOML, служебные статусы и имена файлов не переводятся: их читают инструменты. Эта версия не заявляет полный построчный перевод всей документации.

## Установка

Нужны Node.js 24+, npm и Python 3.11+. Запустить из клона этого форка:

```sh
python3 scripts/shinobi-install.py --runtime codex
python3 scripts/shinobi-install.py --runtime claude
```

Без --runtime обновляются Codex и Claude Code. Скрипт скачивает зафиксированный официальный npm-пакет, вызывает его штатный установщик, затем применяет русский профиль. Никакие npm lifecycle-скрипты пакета не запускаются. Папки, намеренно вынесенные через символьные ссылки, требуют явного флага --allow-symlinked-dest.

Перед изменениями сохраняется локальный архив управляемых GSD-файлов и затрагиваемых настроек. Архив может содержать локальные разрешения: его нельзя публиковать или загружать в общее хранилище. Остальные пользовательские навыки не входят в набор изменяемых файлов.

```sh
python3 scripts/shinobi-localize.py --runtime codex --config-dir /tmp/gsd-test --skills-dir /tmp/gsd-test-skills
```

Команда выше применяет перевод к заранее подготовленной тестовой копии. Установщик Core помещает глобальные навыки Codex в ~/.agents/skills даже при --config-dir; поэтому наш установщик отказывается считать этот флаг изолированной установкой Codex. Новые файлы agents/openai.yaml для GSD не создаются: upstream предупреждает о дублях в некоторых версиях Codex, и русские подписи хранятся в SKILL.md.

После установки начать новый чат или перезапустить соответствующее приложение. Старый чат может сохранять прежний список ролей в своём контексте.

## Обновления

Ветка next сохраняет исходный upstream. Адаптация находится в shinobi-ru, в папке personalization и скриптах shinobi-*. Получать изменения upstream отдельно, просматривать diff, обновлять upstream_version в profile.json и проверять покрытие словаря. Установщик откажется молча пропускать новую неизвестную команду или роль.

Штатный gsd-update обновляет официальный пакет и может заменить русские подписи. После него повторно применить scripts/shinobi-localize.py либо использовать scripts/shinobi-install.py из форка. Не менять номер upstream автоматически без проверки совместимости.

## Проверка

```sh
python3 -m unittest discover -s personalization/tests -v
```

Проверяются повторное применение, сохранение технических идентификаторов, пользовательской политики навыков, исправность TOML и отказ при неполном словаре. Эти проверки не заменяют реальную проверку работы над пользовательским проектом.
